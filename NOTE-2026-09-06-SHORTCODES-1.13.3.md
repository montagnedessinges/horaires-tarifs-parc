# Horaires & Tarifs Parc 1.13.3 — page Shortcodes

La version 1.13.3 remplace directement la page « Shortcodes » de l’administration.

- La page est statique et contient explicitement les 48 shortcodes utilisables.
- 12 modules sont listés.
- Chaque module possède les variantes Automatique, FR, EN et DE.
- Les shortcodes Tarifs groupes, Horaire d’accueil et Guides pédagogiques sont inclus.
- L’ancienne surcouche `Parcs_HT_Feature_Hub` a été supprimée.
- Aucun horaire, tarif, devis, formulaire ou réglage propre à un parc n’est modifié.

Ce fichier sert également à déclencher la chaîne complète de tests et de publication de la version 1.13.3 après le commit de migration réalisé par GitHub Actions.
