# Horaires & Tarifs Parc

Extension WordPress commune pour La Montagne des Singes et La Forêt des Singes.

Le dépôt privé est la source canonique des versions. Les releases GitHub publient un asset `horaires-tarifs-parc.zip` utilisable par le système natif de mise à jour WordPress intégré à l’extension.

Les données propres à chaque site restent stockées dans WordPress et ne sont pas remplacées lors des mises à jour du code.
